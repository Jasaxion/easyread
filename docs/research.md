# 研究工作区与增强阅读

这些能力移植自 [PaperRead](https://github.com/YuriyLin/PaperRead)（`22ccc94`），整合到 EasyRead 现有阅读器、文献库和模型设置中。EasyRead 原有的网页文章、引用导航、译图、离线阅读和桌面数据目录继续保留。

## 开始使用

源码安装后启动：

```bash
python -m pip install -e .
easyread serve
```

打开文献库中的「研究」进入工作区（`/research`）。多标签工作区为 `/web/tabs.html`；可在其中打开文献库、研究页及多篇论文，支持标签重排、分组和分屏阅读。

AI 功能使用「设置 → 模型」中配置的本机 CLI 或 API，不附带模型账号或 API Key。论文搜索使用 OpenAlex 等公开服务；网络不可用时，已经保存的计划、笔记和阅读内容仍然可用。不要把未配置模型或外部服务的失败当作论文内容为空。

## 八类能力

| 能力 | 使用方式 |
| --- | --- |
| 研究工作区 | 搜索论文、筛选结果、加入候选清单、下载到文献库；在阅读看板管理状态、日期与计划。研究进度页管理里程碑和关注主题/作者。 |
| 阅读路径 | 按研究主题生成阅读顺序，查看论文间的引用关系与相关论文；手动调整路线并保存。AI 推荐与外部数据库提供的引用证据分别展示。 |
| 思维导图 | 在阅读页生成论文导图，打开交互视图，编辑节点并保存；再次打开论文后可继续编辑。生成与保存是独立操作，不会把编辑误当成重新生成。 |
| 手写批注 | 手写笔、宽度/颜色设置、橡皮擦、贴纸、文本框、套索与分组。批注随论文保存，并通过现有的操作队列重放与撤销机制管理。 |
| 深度 AI 分析 | 从阅读页分析问题、方法、实验、证据和局限，查看报告、加入论文笔记或导出。分析结果必须回到论文原文核对。 |
| 跨论文分析 | 在多篇文献之间检索片段、扫描关键词、比较方法和研究关联；比较结果经确认后写入知识库。 |
| 增强阅读 | 多标签、分屏、可调整面板、富文本论文笔记、来源引用、图片和导图；保留 EasyRead 既有的原页、引用和网页阅读能力。 |
| 知识库导出 | 在研究设置选择 Obsidian Vault，按论文分析、导图、标注、深度分析、比较、摘要等类型导出 Markdown，亦可下载 ZIP。原有 Markdown 和 HTML 离线导出仍然可用。 |

## 语言与输入方式

- 界面默认使用简体中文，也可选择 English 或繁体中文。
- 单篇论文的 AI 标注、导图、深度分析、笔记助手优先使用论文目标语言；未指定时跟随界面语言。研究摘要、阅读路线和跨论文比较跟随发起任务时的界面语言。
- 英文检索词与英文改写是明确的英文输出工具；原文引句、用户笔记和自定义名称不会被自动转码。已有结果显示其生成语言，不会因切换界面而伪装成新语言结果。
- 手写工具提供“鼠标 / 触摸”和“仅手写笔”两种模式。仅手写笔模式只接受浏览器识别为 `pen` 的输入，并抑制落笔时的误触及兼容鼠标事件。关闭手写后不会继续锁住界面。
- 贴纸按钮独立工作，不会连带打开手写面板。

比较报告可以直接生成、审核并保存在文献库，不再要求先配置 Obsidian；需要时再显式导出到 Vault。多内容 ZIP 下载也不需要 Vault。保存的摘要支持 Markdown 编辑，深度报告可追加到论文笔记，关键词扫描结果可建立和编辑关联图。

## 智慧标注的定位

接受建议时会重新检查当前正文与用户修订，不再只依赖生成建议时的定位状态。原译文改变后，有可靠原文摘录或有效句子对齐的标注可以恢复；无法确定译文对应句时保留在原文侧，可切换双语/原文查看，不会猜测另一句译文。

AI 摘录中的 Markdown、链接、公式和空白会按阅读器的实际显示方式匹配，但不会改写保存的引句。重复接受不会恢复已删除的笔记，也不会覆盖手动修改的笔记正文和颜色。仍找不到来源时显示中性的定位提示，不再一律声称“译文已改”。旧记录没有保存可靠原文锚点、或存在歧义时仍需修改建议或重新分析。

## 后台任务

导图、深度分析和研究比较等耗时操作进入任务监控。可以查看进度、取消任务，完成后打开结果；失败会显示原因，服务重启后被中断的任务可以重新发起。关闭结果提示不等于删除已经保存的内容。

## 检索模型

跨论文语义检索使用 FastEmbed 与 `intfloat/multilingual-e5-small`。首次使用语义检索时需要联网下载固定版本的模型（约 250 MB），后续复用本机缓存。模型文件与索引放在 EasyRead 数据目录的 `.research-os/` 下，不写入论文原文件。索引按文献库与 Vault 隔离，切换文献库不会把另一文献库的结果混进来。

## Zotero 单向同步

文献库支持记住 Zotero 数据目录，再次导入新出现的本地 PDF。同步不会修改 Zotero 数据库、不会覆盖 EasyRead 已有论文的个人分类、笔记或译文，也不会自动复活之前在 EasyRead 删除的论文；需要重新导入的已删除条目应在预览中明确选择。

## 保存、导出与兼容性

- 不移动 `~/EasyRead`，不切换为 PaperRead 的数据目录，不更改已有默认译文语言。
- 笔记、手写和贴纸仍使用每篇论文的 `reader.json`；新字段与旧字段共存。旧论文无需重新导入。
- 研究计划使用文献库内独立 SQLite 数据库，不改写原 PDF。
- Obsidian 导出保留稳定 ID 和托管区块标记。再次导出更新托管部分，保留用户在托管区块之外添加的内容；同名非托管笔记不会被静默覆盖。导出冲突需先查看提示。
- 本地文件夹路径必须是**运行 EasyRead 服务的机器**上的路径；远程浏览器的下载目录不是服务器 Vault 路径。
- 离线 HTML 保留已有内容、笔记和批注；生成新 AI 分析、在线检索和写入服务器 Vault 仍需连接服务。手写笔迹不能作为可编辑笔划直接写入 Markdown，导出时应查看格式提示。
