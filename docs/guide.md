# EasyRead 使用指南

[返回项目首页](../README.md) · [English](guide.en.md)

外部脚本与 Agent 接入：见[开放 API 与 MCP](open-api.md)，支持文档/笔记/划线读取与异步导入，沿用访问保护授权码。

独立的[研究空间](research-workspaces.md)提供项目文件、关联文献、完全权限的原生 Agent 多会话、Git/Beads 与服务端 LaTeX 编辑器；请先阅读其中的私有部署权限说明和各平台依赖安装步骤。

思源笔记可使用 [siyuan-easyread 插件](https://github.com/Jasaxion/siyuan-easyread)：在思源中右键 PDF 附件或文档导入 EasyRead，绑定文章后选择笔记、划线和双语正文同步到快照子文档。请求全部通过思源内核；私有文档无需发布公网。需要支持 `import_html` 的本分支服务；默认不启动翻译。

## 论文白板

打开 **侧栏 → + → 白板**。它与笔记、图表、研究脉络、思维导图、问 AI 同级，每篇文档最多一份。未创建时只显示空面板；点击 **创建白板** 才建立文件并加载 Excalidraw，不会为所有文档预留白板空间。

- 保留 Excalidraw 的自由绘制、图形/箭头、文字、图片、素材库、撤销重做和缩放平移。编辑器菜单可打开 `.excalidraw`、保存文件、导出 PNG/SVG；启用「包含画布数据」后，导出的图片还能拖回编辑。工具栏「导出备份」始终提供包含场景和图片的 `.excalidraw` 文件，素材库另可从原生素材库菜单导入导出。
- 点击上方「全屏」扩大工作区，「退出全屏」或没有打开编辑器菜单时按 Esc 返回侧栏。手机和平板使用触摸工具栏。阅读时点击段落，再打开「⋯ → 插入到白板」即可将整段放到画布当前视野中心，无需在白板中寻找引用入口。默认快捷键为 `V`，可在设置 → 快捷键中修改；原文/译文/双语模式会使用当前显示的语言内容。
- 桌面可把正文选中文字拖入画布，也可点击选文菜单的「白板」。笔记卡片的「白板」按钮支持点击或拖入。未创建时会提示「当前文档没有白板，请先在侧栏创建白板！」，可点击提示中的「打开白板」前往侧栏；不会自动创建或保留这次待插入内容，创建后请重新插入。引用是可编辑的文字快照，不会随原文/笔记自动改变；卡片链接可回到原文。单次引用最多 12,000 字符，长引用可分段插入。
- 白板顶部提供「删除白板」，确认后删除这份白板、预览图和本机草稿，但不影响正文和笔记；此操作不能撤销，请先导出备份。删除整篇文档时，白板与笔记一起进入回收站，恢复文档会一并恢复，永久删除则全部清理。
- 底部显示白板自己的保存状态。断线或保存失败时保留本地草稿（包含图片），重连后重试；重新打开时可恢复/导出草稿。不同页面同时修改会停止覆盖并提示先备份再载入。请等「白板已保存」再关闭；浏览器存储故障时务必导出备份。白板总大小上限 32 MiB，过大时减少图片后重试。
- 编辑器代码、字体与场景在本地服务中提供，不依赖公共白板网站。已打开的画布可以在暂时断线时继续编辑，但 **PWA 不预下载白板编辑器，离线冷启动白板不保证可用；独立 HTML 导出不包含白板**。备份文献目录时包含 `whiteboard.json`，分享/离线迁移请单独导出 `.excalidraw`。未同步草稿会阻止退出授权，可在相应文档的白板中恢复或备份后删除草稿。

白板会在打开及编辑保存后自动生成 PNG 概览（最长边至多 1024 像素）。AI/脚本可通过开放 API 的 `GET /api/v1/documents/<id>/whiteboard` 查看场景和预览状态，再读取 `/whiteboard/image`，沿用访问授权码。尚未生成最新预览时返回 409，不会返回旧图；只通过 API 修改场景不会在服务器启动渲染器，需要打开白板生成预览。详见 [开放 API](open-api.md)。

仅借鉴 [思源集成插件](https://github.com/YuxinZhaozyx/siyuan-embed-excalidraw) 的按需编辑、全屏、主题与来源拖入思路，使用 EasyRead 自身的论文锚点与数据存储，不接入 SiYuan API。Excalidraw 云协作、云分享、任意网页嵌入和执行代码片段不在本集成范围。

## 安装为 PWA 与离线阅读

从文献库 **设置 → 阅读 → 安装与离线阅读**，或阅读页 **Aa → 安装与离线阅读** 进入。阅读时不常驻显示安装按钮；离线时文献库的设置按钮直接打开本机安装与缓存管理。Android Chrome、桌面 Chrome/Edge 可使用浏览器的安装入口；Android Edge 的独立启动行为取决于版本和设备，普通网页快捷方式不等于独立应用。iOS 16.4+ 在 Safari/Chrome/Edge 的分享菜单选择“添加到主屏幕”；旧系统或入口缺失时使用 Safari。安装后优先使用 `fullscreen` 全屏显示；不支持的平台可回退到 `standalone`，iOS 的系统状态栏与显示方式仍由系统决定。全屏显示不等于已生成 WebAPK 安装包。

设置中始终保留“安装到此设备”。浏览器安装弹窗只属于当前页面；没有可用弹窗时会提示从浏览器菜单安装，不表示此设备或其他设备已经安装。独立窗口模式也不作为系统应用安装成功的证明。

- 手机连接服务器必须使用**可信 HTTPS**，仅本机开发可以用 localhost HTTP。局域网 IP 的普通 HTTP 不支持此功能。
- 第一次保持联网，等到“应用已可离线启动”。默认自动保存最近打开的正文、已有译文和笔记；PDF 解析出的正文也可离线读，但**不会下载原 PDF、双语 PDF、原页图或完整 PDF 文字层**。新翻译、AI 问答、导入、研究服务等需要联网。
- 在管理页选择“保存当前文献供离线阅读”或“补齐并固定”，保留正文插图、笔记图片及已冻结的网页快照。显示“部分资源尚未缓存”时，图片或原网页样式可能缺失；正文仍可使用 EasyRead 风格阅读。原网站未能归档的外部资源不能保证离线可用。
- 默认正文/资源预算 128 MB，可选 64–512 MB；空间不足时淘汰较旧的非固定文献，固定文献及有未同步修改的文献不自动删除。清除缓存不删除服务端文献或笔记。应用壳另占少量空间，管理页同时显示站点总占用估算。
- 离线笔记、划线、手写与进度先写入本设备操作队列；在对应阅读页恢复连接并授权后补交；若已关闭阅读页，重新打开该文献即可补交。只有服务端确认且本机快照保存完成，才删除待提交操作。存储不足时按提示导出修改，不要清除浏览器数据。
- 缓存不是备份，浏览器/系统清理仍可能删除它。安装后的应用与浏览器可能使用不同存储，尤其 iOS；请在应用内重新检查离线文献。下载内容是本机副本，服务器无法在设备离线时即时撤权；只在可信设备使用。
- 退出授权会清除本设备当前库的离线副本；有待同步修改时会阻止退出，请先同步或保留导出。发现授权失效后不使用旧缓存代替登录。
- 有新版本时先保存笔记，再关闭所有应用窗口和本站标签页后重新打开，避免正在编辑时强制更新。

**Android WebAPK 与快捷方式不同。** 真正的 WebAPK 应出现在系统“设置 → 应用”中，并可卸载。即使菜单显示“安装应用”，也不代表系统已生成 WebAPK；Chrome 的设备支持、Google Play 服务和安装策略仍会影响结果。可以在“安装与离线阅读”设置中查看安全连接、独立窗口和离线服务状态，但网页无法读取系统包列表。登录页、文献库、阅读页和研究入口共用稳定的 manifest 标识与图标，不会为不同用户或版本生成新应用身份。独立窗口仍使用浏览器运行时；Android WebAPK 与 Chrome 共享站点存储，iOS 主屏幕 Web App 的存储行为可能不同。不要为验证安装随意清除站点数据，先同步或导出未提交笔记。参见 [MDN 安装说明](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) 与 [WebAPK 说明](https://web.dev/articles/webapks)。

该功能不改变 Electron 或单文件离线 HTML 的使用方式。

## 链接后台导入

输入网页 URL、论文链接、arXiv、DOI 或标题，选择好原来的导入选项后点击“导入”：对话框立即关闭，右下角任务胶囊显示提交/导入进度。点击胶囊可切换查看各项导入，并与思维导图、深度剖析等任务共用通知入口。完成后文献库自动刷新，不会打断当前阅读或强制跳转。

如果网络返回 504 或确认响应丢失，会显示“提交状态待确认”，而不是断言导入失败；“确认或重试”沿用原请求 ID，先查找已接受任务，避免重复执行。输入与选项会暂存在当前标签页会话中。刷新或切换到阅读页后，已接受任务由服务器恢复显示；没有自动重新提交。

可取消尚未交接的导入；正在进行的网络请求可能要等超时/返回后才响应取消。已入库文献仍保留，可从任务详情打开。“导入完成”不代表翻译完成，后续仍走原来的预处理/模型队列。勾选的中文 PDF 若启动失败，可在任务详情单独重试 PDF 生成，不重复导入或翻译正文；之后的 PDF 失败仍在文献详情中重试。服务重启后的中断任务请先检查文献库，再手动重试。

任务状态与输入链接保存在本机当前文献库，沿用访问保护。仅关闭通知不会取消服务端任务。原文件上传、Zotero/文件夹导入及开放 API 的使用方式不变。

## 它和“把 PDF 丢给翻译软件”有什么不一样

- **像读一本排好版的中文书。** 宋体正文、舒服的行宽和行距，公式用 KaTeX 按原文重排，表格是三线表，参考文献保留原文；原文的粗体、斜体在译文里照样保留。顶栏一键切深色。
- **随时核对原文。** 一键切“对照”，每段下面附英文；右侧可以开原页，跟着阅读位置翻页，还会框出当前段落在原页的位置。
- **在论文里找内容。** 按 Ctrl / ⌘ + F 同时搜索原文和译文，显示匹配数、高亮结果，用 Enter / Shift + Enter 跳到下一处 / 上一处
- **翻译和解释分开。** 正文只放忠实的译文；AI 的解释、回答放在页边，一眼就能分清哪句是论文说的。
- **沿引用继续读。** 正文中能对应的数字、字母编号或作者年份可跳到参考文献；文末可返回正文引用位置。阅读页左侧“引用”按树状展开本文参考文献和库中引用本文的论文，匹配到库内论文可直接打开，并可返回上一论文的原阅读位置；未入库的条目可通过 DOI/arXiv 或选择本地 PDF 加入并关联，也可搜索。引用关系取自本地已整理的参考文献，并非完整的全球引用索引；匹配不确定时不会自动连线。
- **边读边问 AI。** 右侧“问 AI”面板实时对话，回答逐字流出来；可以一次引用好几段（选中文字拖进输入框就行）。问“我标红的那些公式有什么联系”，它会按颜色找出你的划线。可以开多个对话，模型单独选：Claude、GPT（Codex）、DeepSeek、通义、本机 Ollama……好的回答一键放到页边。
- **ASD-STE100 问答。** 在“问 AI”的“回答方式”里选择这个模式，用简明中文回答问题或总结论文，保留专业术语、公式和数值。模式按对话保存，支持复制、放到页边和导出 Markdown。[ASD-STE100](https://www.asd-ste100.org/STE_faq.html) 是英文标准；这个模式借鉴其短句、主动表达和术语一致等原则，提供中文写作辅助，不将中文答案标为符合英文标准或已认证。正文过长时只提供节选，回答需说明依据范围。
  中文提示词另参考 [asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill) 的语义保留原则：保留条件、范围和“可能／建议／必须”等语气强度，不为简短而丢失精度。
- **精读问答。** “回答方式”里的第三档，适合想弄明白“作者为什么这么做、这个结论能撑多远”的时候：先还原作者要解决的问题，分清哪些设计拿掉就塌、哪些是顺手加的，把关键公式代进具体数字算一遍，再核对正文数字和图表、基线对照条件是否对齐。论文没报告的就直说没报告，不替作者补数字。和简明回答一样会把全文发给模型，用量更多。
- **边读边批注。** 选中文字四色荧光笔或下划线、写笔记、提问；问题一键让 AI 回答，笔记可以让 AI 点评。笔记面板按正文顺序汇总批注，可以筛选、滚动回看；点击卡片定位正文，点“编辑”才改笔记。通过缩略图选择或从正文拖拽，把图表关联到笔记，展开查看或修改图表名称；正文里的图表引用可以悬停预览。可以勾选导出成 Markdown（放进 Obsidian、Notion）
- **译文可以改。** 双击一段直接改；术语表里改一个译法，全文替换。
- **不只是 arXiv。** 拖进任何 PDF；或者填 arXiv 编号、DOI、论文标题、论文网页（OpenReview、ACL、NeurIPS、bioRxiv、PMC、期刊页面），自动找到公开的 PDF 并补全作者、年份、出处。
- **从 Zotero 搬过来。** 导入对话框里点“从 Zotero 迁移整个文献库”，自动找到 Zotero 的数据文件夹，把有 PDF 的论文连同分类（多级照样分层）、标题、作者、年份、期刊、DOI、摘要一起搬进来；只读 Zotero 的数据库副本，不改动 Zotero，可以重复迁移。也能“导入整个文件夹”：选一个放论文的文件夹，子文件夹的层级就是分类的层级。两种都在后台导入、可以中途停止，默认只预处理；可在模型设置中开启“预处理完成后自动排队翻译”。
- **链接本地 PDF。** Zotero 和文件夹批量导入可勾选“链接本地 PDF，不复制原文件”，命令行可用 `--link`。原 PDF 留在原位，缓存、笔记和进度留在 EasyRead；删除论文不会删除原 PDF。链接需要原路径一直可访问，已有论文不会因重复导入而改变存储方式。[用法](linked-local-pdfs.md)
- **文献库。** 侧栏像聊天软件：论文和分类都能置顶；自己建分类（右键改名、删除，把论文拖进去），分类可以分层（右键“新建子分类”“移到…”，点父分类列出所有子分类的论文），内置分类可以隐藏；最近阅读、搜索、未读 / 在读 / 已读、星标、阅读进度、复制引用（GB/T 7714、APA、BibTeX）、导出单文件离线 HTML 发给别人，或者“导出手机版”（只读、体积小，传到手机上用浏览器打开）。删掉的论文先进回收站，可以恢复。快捷键可以自定义。
- **云文献库与批量引用。** 在“设置 → 云文献库”里把文献库迁移到其他磁盘或网盘同步文件夹，也能接入已有的库；原库保留，复制后核对，重启生效。论文列表和分类支持批量复制或保存 GB/T 7714、APA、BibTeX 引用
- **用了多少心里有数。** 每次翻译、每条 AI 回答都记下用了多少 token；用 Claude 订阅时，还能看到 5 小时 / 7 天额度用到多少、什么时候重置。
- **不会丢东西。** 每次修改先存在浏览器，本地服务确认写进文件才删；翻译方后来改了你改过的段落，只提示，不覆盖。

## 手机与平板阅读

- 批注输入框在软键盘弹出、收起和后台更新时保留草稿、焦点与选区；中文输入法组词期间不会触发“结束编辑”快捷键。可点“完成编辑”保存并收起。旋转后页边空间不足时，当前边注暂时以紧凑编辑浮层显示，结束编辑后恢复正常排版。

- 长按正文并拖动系统选区手柄后，可使用屏幕底部的划线、笔记等工具；安卓原生复制菜单仍由系统管理。点击工具时会保留当前选区。普通正文、归档网页和可编辑离线 HTML 共用这一入口；只读“手机版 HTML”仍保持只读。
- **Aa → 边注布局**：选择“自动”时，约 960 CSS 像素以上且字体/侧栏空间允许的平板可直接显示页边笔记；大字号或侧栏开启时会收成角标。“段后展开”在窄屏直接展示各段笔记，“数字角标”保持紧凑。选择会保存；网页原样排版仍通过标记打开笔记面板，也可切换到 EasyRead 风格。
- 手机工具栏保留安全区、扩大触摸目标并显示橡皮/套索等名称；“完成”退出手写。底部提示和安装入口避让批注工具。

## 手写与贴纸

iPad Safari（含主屏幕 PWA）默认启用「iPad 手写优化」：实时笔迹在独立、屏幕大小的 SVG 图层中逐帧更新，不改动整页历史笔迹；浏览器支持时优先读取合并采样并保留细小移动，动画帧延迟时提供 150ms 的实时补绘兜底；抬笔保留末端位置并通常只追加当前笔画。书写与手指拖动期间的非必要整层重绘合并到手势结束后，真实布局变化时先保存笔画再移除预览，避免补绘空档。仅手写笔模式的手指拖动仍按帧更新滚动，落笔立即取消待执行的拖动。Pencil 接触期间拦截手指和手掌；丢失事件捕获不等同于抬笔。已接触的手掌须离屏后才能作为新手势使用，切换工具也不会把仍贴着的手掌重新当作点击。抬笔后允许新的手指手势。连续书写时，每笔立即写入本机待同步队列，但不再反复复制全部阅读状态、扫描全部已写队列；后台同步快照和远端刷新等待输入短暂停稳。异常的零压力/零按钮移动不再被当作抬笔。手指开始拖动会取消旧的阅读位置恢复，正文后台分块排版也避开正在进行的笔画和拖动，减少滚动回拉。笔迹存储格式不变，Android、桌面及其他浏览器沿用原绘制与滚动路径。若某台 iPad 表现不佳，可在 **设置 → 阅读 → iPad 手写优化** 关闭，下次手势恢复原行为。它不增加原生惯性滚动或画布内双指缩放，也不保证达到系统笔记应用的手感；Apple Pencil 的实际跟手性仍需真机确认。

“手写”和“贴纸”独立开启：打开贴纸素材库会关闭手写工具，不会启用画笔。手写工具默认使用“鼠标 / 触摸”，可点击输入方式按钮切换为“仅手写笔”；选择会保存在当前浏览器。仅手写笔模式下，画笔、橡皮擦、套索和文字放置只接受浏览器识别为 `pen` 的输入；鼠标不能绘制，但未落笔时可用手指拖动画布滚动，也可用滚轮、触控板和滚动条阅读。画布上的手指滚动由应用处理，保留 `touch-action:none` 防止浏览器把笔触变成页面滚动；这不是原生惯性滚动，也不提供画布内双指缩放。落笔期间拦截误触、选文和菜单，并终止未结束的手指拖动；抬笔后可用新的手指手势或鼠标配置工具、退出，键盘仍可使用。网页原始排版会在开启手写时切换到已有的 EasyRead 正文排版；切回网页原排版会关闭手写。关闭手写后恢复普通阅读和贴纸操作。设备若把笔上报为鼠标，请主动切回“鼠标 / 触摸”；此时不提供手掌防误触。macOS + 数位板优先推荐 Chrome：如果 Safari 仅上报 `mouse`，网页无法可靠区分数位笔和普通鼠标，不会通过压感猜测笔类型。Safari 会在滚动停止后请求一次批注和贴纸补绘，不改变 Chrome 的现有绘制路径。

**Codex 自定义模型目录**：翻译和问答的模型下拉框优先读取 `$CODEX_HOME/config.toml`（默认 `~/.codex/config.toml`）中的 `model_catalog_json`；相对路径以该配置文件所在目录为基准。没有配置时读取同目录的 `models_cache.json`。自定义目录替代缓存，沿用其可见模型、顺序和推理强度（包括模型支持的 `ultra`）。目录文件修改后点“重新检测”即可刷新 EasyRead 的名单；目录为空、缺失或格式错误时不回退显示旧缓存。此检测只读取本地文件，不发起模型请求，也不修改 Codex 配置。缺少目录/缓存时会显示原因，并可使用配置中的默认型号作为候选。模型栏始终允许手工填写服务商支持的模型 ID，留空才是跟随 CLI 默认；候选不代表服务商已验证可用。要使用不同型号，请填写不同 ID，仅修改卡片名称不会切换底层模型。

默认逐篇翻译，单篇内部仍可分段并发。在“设置 → 模型 → 翻译”中可将“同时翻译几篇”设为 1–4 篇，重启后生效。多篇并行会叠加分段并发，增加内存和模型限流风险，建议保持默认 1 篇；详见[配置说明](paper-concurrency.md)

**预处理与翻译分开排队**：PDF 渲染、抽取文字使用独立的单 worker 队列，不占用“同时翻译几篇”的名额。另一篇论文预处理时，已准备好的论文可以翻译。在详情或阅读页点击“预约翻译”（批量“翻译”也支持），这篇会优先预处理，完成后自动进入翻译队列；不会打断当前正在预处理的论文。同一篇仍须先完成预处理才能翻译。界面分别显示“等待预处理／正在预处理 PDF”和“等待翻译／正在翻译”。

**自动接续翻译（可选）**：在“设置 → 模型 → 翻译设置”开启“预处理完成后自动排队翻译”。明确允许自动翻译的 Zotero／文件夹导入任务，在成功准备后自动加入翻译队列尾部，沿用任务的模型、语言和页数范围。此开关默认关闭；保存后对尚未完成的预处理立即生效，不会追补历史已完成论文。翻译会消耗模型额度，超过页数阈值仍先确认。缺少自动许可字段的旧任务、导入时明确选择“只导入”、公开 API 的 `translate=false` 和研究导入不受此开关影响。阅读页“重试预处理”始终只准备原页；需要翻译时请明确点击“预约翻译”或“翻译”。

单篇“取消”会停止这篇的任务及预约；“停止模型任务”也会撤销尚未开始的自动翻译，但 PDF 预处理继续，不会在准备完成或重启后自行恢复自动翻译。预处理出错后不会启动翻译，可修复原因后重试。重启恢复未完成任务，已保存的译文保留。关闭自动开关只阻止后续自动接续，不取消已进入翻译队列或明确预约的任务。停止模型任务只处理当时已有的请求；若批量导入仍在继续，新任务仍可能加入，请同时停止导入或关闭自动接续。正在运行的模型取消意图会先落盘，重启不会恢复已取消请求。

**生成译图（可选）**：在“设置 → 模型 → 翻译设置”打开“生成译图”，默认使用 **Codex 订阅**：需要安装支持内置生图的 Codex CLI，并使用 ChatGPT 登录，不需要另填 API Key。生图消耗订阅额度，具体限制见 [Codex 生图用量说明](https://learn.chatgpt.com/docs/pricing)。不可用或额度不足时，回退到原图和文字译文，**不会自动调用单独计费的 API**。也可主动选择“图片 API（单独计费）”，填写兼容 Images Edits 的地址、模型和 Key。

翻译先保存正文和图内文字，再按这篇论文的目标语言生成译图，尽量保留原图布局。图片沿用正文的“原文／译文／双语”设置：分别显示原图、译图或两者，双语顺序也同步。有可用译图时不重复展示图内文字译文；没有可用译图或加载失败时，显示原图和文字译文。离线导出保留相同的切换和兜底能力。功能默认关闭；开启后自动为后续翻译生图，并显示已有论文的补图入口。生成结果不保证逐像素保真，图表细节可与原图对照。

**已翻译论文补图或重新生图**：先在设置中开启“生成译图”，然后打开论文，在标题下点击“为本文生成译图”，只补齐缺失或已过期的译图；单张图片下可点击“生成译图 / 重新生成译图”，也可从图片右键菜单操作，无需重译正文。关闭开关时，这些入口和失败重试入口都会隐藏，已有译图保留；正在运行的任务仍可查看进度和取消。手动修改过的图内文字会作为生成参考；旧论文没有保存图内文字时，直接根据原图翻译。失败时保留已有图片、译文和笔记。

## 安装

**最省事：下载安装包**（不用装 Python）。在 [Releases](https://github.com/Edwardxlai/easyread/releases/latest) 下载：

- **Windows**：`EasyRead-Setup-x.x.x.exe`，双击安装。没有代码签名，如果弹出“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”。
- **macOS**（Apple 芯片）：`EasyRead-x.x.x-arm64.dmg`，把 EasyRead 拖进“应用程序”；第一次打开被系统拦截时，按下面对应的提示处理
- **Linux**：`EasyRead-x.x.x.AppImage`，`chmod +x` 后运行。
- 如果 Linux 提示缺少 `libfuse.so.2`，可按 [AppImage 官方说明](https://docs.appimage.org/user-guide/troubleshooting/fuse.html)配置 FUSE，或在独立目录运行 `./EasyRead-x.x.x.AppImage --appimage-extract`，再运行 `./squashfs-root/AppRun`；无需关闭沙箱

论文和设置存在哪：Windows 安装版在安装目录下的 `data` 文件夹（装在 D 盘就在 D 盘，更新和卸载都会保留）；macOS、Linux 在用户目录下的 `EasyRead` 文件夹（和 pip 安装版同一个位置）。卸载重装不会丢。

以后升级：Windows、macOS 安装版和直接打开的 Linux AppImage 都可以在程序里更新，有新版本时顶栏会提示（也可以在右上角问号里手动检查），点“更新”，可以放到后台下载，下好后点“更新并重启”。解压运行的 AppImage 和从源码运行的照旧从 Releases 下载新版。macOS 和 Linux 从 1.3.2 及以前升级时，要先手动下载 1.3.3 一次；macOS 要把 EasyRead 放在“应用程序”里才能在程序里更新。

### macOS 首次打开

1. **提示“无法验证开发者”或“Apple 无法验证是否包含恶意软件”**：先点“完成”（不要点“移到废纸篓”），打开“系统设置 → 隐私与安全性”，向下找到安全性提示，点“仍要打开”；在确认窗口点“打开”，按提示输入登录密码或使用 Touch ID
2. **提示“已损坏，无法打开”**：先从 [EasyRead 官方 Releases](https://github.com/Edwardxlai/easyread/releases/latest) 重新下载，并把应用拖进“应用程序”；文件也可能确实损坏或被改动，不能只凭这条提示判断原因。只有确认文件来自这个官方仓库、并信任该文件后，才在“终端”执行下面的命令，再重新打开 EasyRead；这条命令移除隔离属性，不会修复损坏的文件

   ```bash
   xattr -dr com.apple.quarantine /Applications/EasyRead.app
   ```

3. **为什么会出现验证提示**：目前的 macOS 安装包用的是项目自己的自签名证书（为了应用内更新），不是 Apple 开发者证书，也没有经过公证，因此可能被系统拦截；代码完全开源，也可以[从源码运行](#run-from-source)

如果系统提示“将损坏你的电脑”，或明确检测出恶意软件并要求移到废纸篓，请停止安装，不要用上面的步骤绕过；按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 处理

**或者从源码运行**：需要 [Python 3.10+](https://www.python.org/downloads/)。

先从 [Releases](https://github.com/Edwardxlai/easyread/releases/latest) 下载最新版的 zip 解压（或者 `git clone` 本仓库）。

**Windows**：双击 `start.cmd`。第一次会自动装好环境（一分钟左右），之后双击直接打开。

**macOS / Linux**：在解压出来的目录里运行

```bash
./start.sh
```

这样启动的，浏览器里的 EasyRead 页面全部关掉后，后台服务过十几秒会自己退出；还有翻译在跑的话，等译完再退。

合入 main 和提交 PR 时，CI 会在 Windows、macOS、Linux 上安装、运行测试并启动服务。

**或者用 pip**（数据放在 `~/EasyRead`）：

```bash
pip install git+https://github.com/Edwardxlai/easyread
easyread
```

浏览器会打开 `http://127.0.0.1:8765`。服务默认只监听本机。

**Docker / 服务器部署**：单容器、单端口，包含 Claude Code、Codex CLI、Chromium 和 BabelDOC。在“设置 → CLI 与终端”使用内嵌终端登录/更新，在“访问保护”管理可选授权码，在“网络与代理”配置全局代理。没有账号密码弹窗或第二个终端网址。详见 [完整 Docker 部署说明](docker.md)。

### AI 问答的 CLI 能力

在“设置 → 模型”中打开 Claude Code / Codex / Pi Agent 卡片菜单，选择“AI 问答 · CLI 功能管理”。默认保持原来的精简设置；可以切换完整原生模式或自定义工具、Skills、MCP，并导入问答专用 Skill。每个模型条目的模式和启用策略独立保存，也可选择“继承 CLI 默认”兼容原配置；共享的是 CLI 安装、原生配置与 Skill 文件。**不改变翻译及其他自动处理**。详见 [问答 CLI 设置](qa-cli.md)。

## 桌面版（Electron）

桌面版复用同一套本地 Python 服务和 Web 界面，由 Electron 负责启动服务并显示窗口。开发环境需要 Node.js 22+、Python 3.10+ 和 PyInstaller：

```bash
npm install
python -m pip install pyinstaller
npm run dev
```

生成可分发安装包：

```bash
npm run dist
```

输出在 `dist/electron/`：Windows 为 NSIS 安装程序，macOS 为 DMG（另有一个给应用内更新用的 zip），Linux 为 AppImage。macOS 包由 `scripts/mac_sign.cjs` 用固定的自签名证书签名，证书从环境变量 `MAC_SIGN_P12`、`MAC_SIGN_P12_PASSWORD` 读（发版时来自仓库 Secrets）；本机没设时退回临时签名，这样打出的包不能应用内更新。推送 `v*` 标签后，GitHub Actions 会在三个系统上构建，并把这些安装包自动附加到 GitHub Release；源码 zip 仍会由 GitHub 保留。打包后的文献库和设置：Windows 存在安装目录下的 `data`（安装目录写不进去时退回 `~/EasyRead`），macOS、Linux 存在 `~/EasyRead`。

**网页与部署**。粘贴博客链接可以保留网页排版，在段落上划线、提问或导出离线 HTML。动态页面需要本机 Chrome 或 Edge。[网页阅读指南](web-articles.md)。部署可用 `EASYREAD_TARGET=zh-Hant` 指定默认译文语言，已保存的语言设置优先。

1. 右上角“设置” → “模型”：添加要用的模型，点卡片选“设为翻译”。翻译和“问 AI”用的模型都在这一页管理。
2. 把 PDF 拖进窗口；或者粘贴 arXiv 编号、arXiv / OpenReview 链接、PDF 直链（在文献库页面直接 `Ctrl+V` 也行）。长论文可以选“只译正文”，或者“指定页”只译第几页到第几页。导入时还能选这次用哪个模型；“导入后”选“读英文原文”就只排版、不翻译，想看中文了随时点“翻译成中文”。
   整篇翻译默认超过 60 页时会先确认，可以选择全部翻译、只译前 60 页或先不译；上限在“设置 → 模型”里修改，填 0 表示不询问
3. 翻译在后台一页页进行，已译的部分马上能读，没译到的页先显示原页。一次导入超过 5 篇时会先问要不要全部翻译（默认只导入）；想停下来，点列表顶部的“停止翻译”，已译的部分保留。
4. 读的时候点一下段落出现操作条；选中文字可以划线、写笔记、提问。快捷键在“设置 → 快捷键”里查看和修改；遇到问题点右上角的问号。
5. 论文默认译成中文，也可以在导入时选择繁体中文、英语、日语、韩语、西班牙语、法语、德语或意大利语，或在“设置 → 阅读 → 论文译成”里修改默认语言；界面语言独立设置，支持简体中文、繁体中文和英文，也可以跟随系统。内置阅读状态、侧栏、菜单及状态编辑器跟随界面语言；旧版本保存的默认名称也会正确显示，但自定义分类、状态名称、论文和笔记内容不会被转换。授权页面默认跟随应用语言，页面上的临时语言选择不修改全局设置

## 和 AI agent 一起读

EasyRead 自带命令行，Claude Code / Codex 这类 agent 可以在对话里直接读你的笔记和问题、把回答写到对应段落旁边，也可以亲自翻译或重译某几页。技能说明在 [`skill/paper-reading/SKILL.md`](../skill/paper-reading/SKILL.md)，把这个目录放进 `~/.claude/skills/` 或 `~/.codex/skills/` 即可。

想让 agent 把一篇论文**讲透**而不是只译出来——还原作者真实的思考起点、把关键公式落到能自己算的例子、再把结论的边界查一遍——用 [`skill/paper-xray/SKILL.md`](../skill/paper-xray/SKILL.md)。它读的是同一份 `library/<ID>/`，谈出来的东西照样写成锚在段落旁的讨论条目。

```bash
easyread list                          # 列出文献库
easyread import 论文.pdf                # 或 arXiv 编号 / 链接
easyread status ID                     # 进度、我改过的译文、笔记、待回答的问题
easyread discuss ID --from 回答.json    # 把讨论写到页边
easyread export ID                     # 导出单文件离线 HTML
```

完整命令见 `easyread --help`，数据格式见 [docs/data-format.md](data-format.md)。

## 常见问题

**能翻译成中文以外的语言吗？** 能，目前支持简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语和意大利语。在“设置 → 阅读 → 论文译成”里修改默认语言，也可以在导入时单独选择；读德语、法语等非英语论文时也可以译成英语。不需要翻译时，可以直接读英文原文

**翻译到一半失败了？** 文献库里点这篇，右侧“翻译”一栏会写原因和失败的页，点“重试”。“翻译记录”里有每一批的详细情况；设置底部“运行日志”能看到服务本身的日志。

**用 Claude Code 要挂梯子吗？** 和你平时在终端里用 `claude` 一样：平时要，这里也要。不想折腾就在设置的“API 接口”里选智谱、硅基流动（都有免费模型）或本机 Ollama，国内直连。

**Claude Code 额度用完了？** 等额度恢复后点“重试”，或者在设置里临时换成 API / Ollama，已经译好的页不会重译。

**数据存在哪？** 默认保存在本机；在“设置 → 云文献库”里可以迁移到其他磁盘或网盘同步文件夹，上传和同步由你自己的网盘客户端完成。翻译和提问时，相关内容会发给你选择的模型。Windows 安装版在安装目录的 `data\library\`（1.3.1 及以前放在 `~/EasyRead`，升级后第一次打开会自动搬过去）；从源码运行时在项目目录的 `library/`；pip 安装后在 `~/EasyRead/library/`。每篇论文一个文件夹，里面是原 PDF、原页图和几个 JSON（译文、你的笔记、AI 讨论、对话记录），设置和界面偏好在 `config.json`、`prefs.json`。可以直接备份或同步。为什么不用数据库见 [docs/data-format.md](data-format.md#为什么用-json-文件而不是数据库)。

**能离线看、发给别人吗？** 能。文献库里右键一篇论文 → “导出离线 HTML”，得到一个单文件网页（命令行是 `easyread export ID`）。对方不用装 EasyRead，双击用浏览器打开就能读：译文、公式、原页图、你的划线和笔记都在里面，也能切对照、开原页、接着划线。原页图是打包进去的，所以文件不小（27 页的论文约 10 MB）。在离线版里新做的划线和笔记只存在打开它的那个浏览器里；想并回文献库，在左侧“说明”里点“导出我的修改”得到一个 JSON，再运行 `easyread merge ID --from 导出.json`。

**中文 PDF（可选）：** 在“导入论文”中勾选“生成中文 PDF”，每次打开都默认关闭。勾选后选择输出目录；也可点“仅生成翻译后的 PDF”，选择原始 PDF 后直接生成，暂不翻译阅读器正文；已经填入链接时使用该链接，没有输出目录时会提示选择。使用导入框所选模型翻译整篇原始 PDF，保留排版，将 `原文件名-zh.pdf` 自动保存到所选目录；同名文件会自动加序号，不会覆盖。这会额外消耗模型额度，不包含阅读器中的手动修改或笔记。选择 Codex 时沿用已有 ChatGPT 登录；API 模型使用已保存的配置。生成期间可照常阅读，完成后在论文详情里查看保存位置或下载，失败时可查看原因并重试。文献库的 `babeldoc/` 子目录也保留一份结果，已生成的中文 PDF 可直接保存到其他目录，无需再次翻译

先安装 BabelDOC 命令（与 EasyRead 的 Python 环境分开）：

```sh
uv tool install --python 3.12 --with 'bitstring<5' --with 'onnxruntime==1.23.2' BabelDOC
```

BabelDOC 0.6.4 目前若装到 `bitstring` 5.0.0，会因缺少 `BitStream` 而无法启动，因此这里限制在 4.x。本机测试使用 ONNX Runtime 1.23.2。已安装过不兼容版本时加 `--reinstall` 重装。翻译会消耗所选模型的额度

想放到网站上（比如 GitHub Pages），用 `easyread demo ID --out 目录`：图片另存成文件、按需加载，还会带上问 AI 的对话记录（只能看）。
